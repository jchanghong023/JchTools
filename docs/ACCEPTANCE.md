# Windows 发布验收清单

下面是待执行验收，不是测试已通过的声明。所有破坏性场景使用专门的可丢弃测试目录或测试卷。

## 构建与界面

Windows x64 Rust stable/MSVC 全量编译；运行默认核心测试及显式真实引擎测试；PowerShell 脚本语法解析。启动/关闭/搜索/侧栏/规则切换/导入导出/原生目录对话框/双阶段确认/冲突逐项和全部应用/计划分页勾选/日志导出实际操作。检查 100%、150%、200% DPI、中文、亮暗主题、高对比度、远程桌面及软件渲染。分别测冷启动和热启动，不能把进程创建时间代替首个可交互窗口时间。

## 文件正确性

ZIP、7Z 固实包、RAR4/RAR5、TAR、TAR.GZ、BZ2、XZ、ZST；嵌套包、重复条目、乱码文件名、空包/空目录；加密、CRC 错误、截断包、超深嵌套、路径逃逸、链接、分卷缺失。覆盖/跳过/最新/最大/两份保留；任何未完整解压或部分跳过的原包必须留下，分卷源文件不能被后续 Hash/版本清理删除。

所有去重开关组合；相同大小不同中间字节；旧/新 mtime 相等；真实重复但文件名不同；同名不同内容；已有硬链接；计划生成后源文件、保留文件或目标路径被外部进程改变。取消删除项导致目标未腾空时，后续移动必须安全失败而不是覆盖。重复执行相同分类规则不应出现分类目录套分类目录嵌套。

## Windows 删除与文件系统

本地 NTFS 正常回收；限制回收站容量后回收大文件；禁用目标卷回收站；USB/不支持回收的位置；UNC/映射盘；回收失败降级开关分别开启与关闭；Shell 用户取消与应用取消不得触发永久删除。验证日志明确区分回收与永久删除，源文件和回收站内结果符合选择。

只读、共享占用、ACL 拒绝、Unicode 与长路径、reparse/junction、文件/目录重名、大小写冲突、磁盘空间不足。不要在真实生产网络共享上首次验证降级逻辑。

## 压力与中断

百万级目录项和数 TB 真实数据；单个数 TB 文件、单个大固实包、大量小文件。记录首屏、扫描/预哈希/完整 Hash/执行阶段时间、峰值 RSS、引擎内存、DB 与 staging 峰值占用、磁盘吞吐、取消响应、UI 卡顿。稀疏文件不能替代真实 TB IO 测试，也不能据此宣称真实性能。

正常取消、关闭窗口、子进程失败、应用强杀、磁盘断开；验证不自动重放历史删除、不清空别的 UUID 工作区，不把日志当成回滚机制。源包删除后已完成输出应存在；损坏/失败原包应保留。异常残留工作区供人工检查。

## 发布内容

独立干净 Windows 测试机，无安装版 7-Zip，无 Rust，无相关 PATH，运行完整便携包；篡改/缺失引擎触发拒绝；`7z.exe` 与 `7z.dll` 版本一致；许可证、Slint 署名、7-Zip 对应源码、Cargo.lock 和实际 BUILD-INFO 保留。不要把本次源码环境的静态检查记录说成 Windows 的运行验收。
