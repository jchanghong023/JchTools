## 1. 定位与行为不变

- **XB-01【推理提供方】** 文档转换、文档及独立图片 OCR、截图 OCR（O-07 固定模型字节）与媒体转录（T-19 链路）由固定版本的 Xberg 发布物承接，全部调用遵守 XB-14～XB-17；JchTools 保留工具注册表与 Slint 页面、扫描/过滤/排序/队列/超时/停止等任务控制、截图服务的独立后台进程、托盘、全局热键、单实例、开机启动、模型常驻监督、框选与结果窗（O-11～O-22）。
- **XB-02【行为不变】** 迁移后截图 OCR 的识别、瓦片与二维布局行为仍满足 O-23～O-28 及附录 B；媒体转录仍满足 T-19/T-20 与附录 C。验收沿用对应文件的既有口径（同图对照、桌面 E2E、合成媒体逐项断言）；旧实现的既有通过记录不得当作迁移后证据。
- **XB-03【两套模型明确区分】** Xberg 侧文档 tiny 与截图 small 两套 OCR 模型分别命名、分别校验、显式选择；JchTools 不得依赖或利用任何「同属 PP-OCRv6」的混用、覆盖或自动回退（对应 Xberg 草案 SNAP-02～SNAP-06）。

## 2. 本地调用接口

- **XB-05【接口形态】** JchTools 通过唯一 Xberg 的本地 worker 协议（`xberg worker`，stdio JSON 行）承接全部功能请求（XB-14）：截图以图像字节（base64，无损编码）传参，不要求落盘；文档转换与转录传本地文件路径。每请求恰好一行响应，成功携带对应的文档结构、布局文本或转录结构，失败携带可分类错误；请求与响应明确关联，协议支持 XB-15 的跨场景并用，不因共享通信连接而串错结果或将截图排在当前文档结束之后。
- **XB-06【模型选择参数】** 共享 worker 的能力配置显式声明各场景的模型集及独立配置，包括文档 OCR、截图模型集 `snapshot-pp-ocrv6-small-textsnap` 与 SenseVoice 链路；各请求显式选择其场景，模型与配置按 XB-16 隔离并复用。请求与已配置能力不匹配时返回明确错误，不自动切换模型，不通过另起进程处理错配。
- **XB-07【错误类型】** 至少区分：资产未就绪、模型/字典校验失败、模型错配、输入解码失败、无文字（截图）/无音轨/无语音（媒体）、超时、用户取消、内部失败；界面文案沿用 O-30 / T-24 的分类与措辞约束。
- **XB-08【取消边界】** 取消、停止和超时按请求及所属场景隔离（XB-17）：截图取消按 O-19 在当前不可中断推理调用返回后的瓦片或识别批次检查点生效；文档及媒体批次停止按 T-23 等待当前文件结束，单文件超时按 T-29 结束该文件的本次处理。不得以关闭共享连接、终止共享进程或进程组处理正常取消与单文件超时；不得影响另一场景的任务或模型。取消与超时不得伪造成成功，已完成部分按 T-23/T-25 语义处理；进程自身异常退出按 XB-17 报错和恢复。
- **XB-09【版本兼容】** Xberg 运行组件携带可校验版本标识（发布 tag 与组件清单摘要）；与 JchTools 内置期望不一致时明确报错并指引更新对应组件，不自动降级、不混用其他版本、不因「同名文件」认定兼容（呼应 T-06 精神）。

## 5. 全部功能共用一个 Xberg 进程（2026-09-29 已确认）

用户本次明确要求：Xberg 支持模型常驻；截图推理与文档转换使用不同模型和配置，文档转换期间仍须支持截图推理；进一步明确「全部功能，只能共用一个 xberg 进程」。以下四项已由用户逐条确认；相关旧条目同步修订，模型、输出、隐私及各工具功能边界仍按对应功能合同执行。

- **XB-14【已确认：全部功能唯一共享进程】** 同一 Windows 用户会话内，JchTools 全部使用 Xberg 的功能共用至多一个活动 Xberg 引擎进程，包括文档转换、文档及独立图片 OCR、截图推理、媒体转录；多功能启用时全部由同一个进程承接，不能按功能、模型、配置、运行目录、文件或请求另起 Xberg，也不能以预检或辅助调用为由启动第二个 Xberg 进程。单进程限制指 Xberg 引擎，不要求将 JchTools 主界面、截图托盘服务合并成一个进程；仅使用其中一种功能时仍保持其独立可用。
- **XB-15【已确认：转换期间可识别截图】** 文档转换正在处理当前文件时，热键或托盘发起的截图仍能在同一 Xberg 进程中执行识别并返回结果，不得等当前文档或整批转换结束后才开始截图推理，也不得停止或重启文档转换来切换场景。T-22 的顶层文件串行只约束转换任务之间，O-19 的单任务限制只约束截图任务之间；两者不构成跨场景互斥。资源竞争按 O-32 如实衡量，不新增固定延迟或零性能损失承诺。
- **XB-16【已确认：场景模型、配置与常驻隔离】** 同一 Xberg 进程按场景分别持有模型及配置；截图沿用 O-07 / O-23～O-28，文档转换沿用 T-13～T-18 / T-29 与 XB-03，媒体转录沿用 T-19 / T-20，不混用模型、字典、阈值、线程设置或文档快速模式。截图与文档转换两套已加载模型可同时驻留并在各自功能持续使用期间复用，不因另一场景开始、结束或每次请求而卸载重载；截图预加载与关闭主窗口后的常驻仍按 O-11 / O-13。模型常驻不扩大 O-29 的截图及结果保留范围。
- **XB-17【已确认：停止与生命周期隔离】** 截图取消或托盘退出只结束截图任务、释放截图资源，不中断正在执行的转换；文档停止仍在 T-23 的当前文件结束后生效，单文件超时仍按 T-29 结束该文件并如实处理后续任务，不停止截图服务或卸载其模型。正常取消、单文件超时与任一功能退出不得通过杀死共享 Xberg 进程实现。关闭或重开主界面仍按 O-11 / O-16 / U-09 处理，不能产生第二个 Xberg；共享进程自身异常退出时，受影响任务明确报错、不伪报成功，重新建立进程仍须满足 XB-14。
