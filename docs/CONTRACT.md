# JchTools 需求合同（CONTRACT）

> **地位**：本项目两份权威文档之一，与 `AGENTS.md` 并列。本文档**只写需求**——软件必须满足的行为；项目背景、开发纪律、怎么测试、怎么验收见 `AGENTS.md`。其余文件均为辅助说明，与权威文档冲突时以权威文档为准。
>
> **维护规则**（详见 `AGENTS.md` 第 8 节）：条目只增不减；增改必须经用户确认；代码与需求不一致时修代码，`MUST NOT` 为迁就代码现状而改写本合同。
>
> 2026-09-17：本合同经用户逐项确认全面重建（原 62 条 → 现 59 条）。移除项：命令行界面（原 L 分区）、报告导出、同名版本取舍（原 R-05）。

## 0. 产品定位（P）

- **P-01** JchTools 是用户个人使用的 Windows 本地工具箱；「目录整理」只是其中一个工具的名称，`MUST NOT` 用作产品名。
- **P-02** 工具经统一注册表（id / 名称 / 类别 / 摘要）接入，侧栏导航只遍历注册表；不设空占位分类。当前两个工具：目录整理（文件类）、代理工具（网络类）。
- **P-03** 全部处理在本机完成；`MUST NOT` 上传文件、日志或路径。
- **P-04** 界面中文；浅/深主题跟随系统并可在「关于」页切换；颜色一律走统一设计令牌（Design 全局）。
- **P-05** 个人使用场景：交付形态为便携 ZIP；不要求安装器、代码签名与公开分发的验收。
- **P-06** 范围边界：不提供命令行界面（全部操作经图形界面完成）；不提供整理报告及任何形式的报告导出（含 CSV）。

## 1. 目录整理 · 主流程（C）

用户主流程固定三步，默认配置即满足：**① 解压 → ② 跨目录内容去重 → ③ 归类与清理**。

- **C-01** 选择目录 → 会话内调整规则 → 第一次确认启动「解压与分析」。第一次确认已经修改目录（解压、解压冲突处置、按设置处理原压缩包），不是只读预览；界面必须如实告知。
- **C-02** 解压：将目录内压缩包（7Z/ZIP/RAR/TAR/GZ/BZ2/XZ/ZST/TGZ/CAB/ISO/WIM 等候选后缀，实际能力以捆绑引擎为准）递归解压，含嵌套包。
- **C-03** 解压冲突：**默认尽量保留修改时间（mtime）最新的文件；无法判定哪个最新（mtime 相同）时，保留体积最大者**。另可选逐次询问（可应用后续全部）、覆盖旧文件、跳过新文件、保留较大、两份都保留并重命名；覆盖或淘汰旧文件必须走用户选择的删除策略。
- **C-04** 去重：输入目录内**跨目录**、跨名称的相同内容文件全部参与去重，**每组只保留一份，其余删除**；判定范围三类（同名、`(1)/Copy/副本` 名、不同名同内容）默认全部启用；默认保留 mtime 最新（平局见 S-11）。
- **C-05** 归类：解压与去重完成后分类；默认按大类（视频、文档、图片等，未匹配的入「其他」），可选按扩展名、按修改日期、按自定义扩展名规则或不归类；默认在分类目录内保留原相对路径（可选扁平归类，同名自动改名）；归类输出目录名称默认留空，即分类目录直接建在所选目录根下；重复执行幂等（分类目录不套娃）。
- **C-06** 清理：整理结束后输入目录**不得残留任何空目录，也不得残留嵌套的空目录链**（自底向上清理，仅删除实际为空的目录，绝不递归删除用户目录）。
- **C-07** 分析完成生成**分页计划**（不自动执行）；可逐项勾选/取消（先落任务库）；第二次确认后执行计划。
- **C-08** 状态机 `analyzing → ready → executing → finished`，异常转 `failed`、取消转 `cancelled`；用户主动取消不算失败；非 `ready` 的旧任务不得再次执行；无断点恢复、无任务重放。
- **C-09** 运行中关闭窗口必须弹「停止任务并关闭」确认，且始终盖在解压冲突对话框之上；暂停/取消在 Hash 分块边界生效，已启动的整包解压排空该包后暂停。
- **C-10** 改变规则或目录后执行按钮失效，必须重新分析。
- **C-11** 计划行显示中文状态（待执行/已执行/已跳过/已取消勾选/执行失败）；翻页按钮仅在上/下一页真实存在时可用；切换类型筛选回到第一页。
- **C-12** 运行日志最新在上、界面仅保留最近 300 条；不提供报告或日志导出（见 P-06）。
- **C-13** 提示两级：信息蓝条、错误红条，可分别关闭；用户取消不得报成错误。
- **C-14** 相同规则重复整理结果幂等；用户手工改动或规则切换可产生新计划。

## 2. 数据安全不变量（S）——最高优先级，与其他需求冲突时优先

- **S-01** 任何移动/改名 `MUST NOT` 带覆盖语义；旧文件先按已授权规则处理，再放置新文件。
- **S-02** 删除一律走配置的回收/永久策略；Windows 回收必须走系统回收接口（不得用普通删除冒充）；回收失败仅当用户开启降级才永久删除（该降级默认开启）；用户取消与应用取消 `MUST NOT` 触发降级；系统返回含糊「已中止」时按取消保守处理。
- **S-03** 内容去重必须完整哈希（BLAKE3）一致才判定重复；删除前逐字节复核，该复核不可关闭。
- **S-04** 计划生成后源/保留文件/目标的元数据（大小、mtime）变化即跳过或失败，`MUST NOT` 以覆盖方式「自动修复」。
- **S-05** 压缩包危险条目（路径穿越、绝对路径、符号链接、加密、非 UTF-8 名称）拒绝或跳过；加密、损坏、警告退出、部分跳过、分卷来源不确定的原包强制保留。
- **S-06** 解压先写同卷独立工作区（随机 UUID 标记），成功后以不覆盖改名合入；空间不足保留源包并报错（默认预留 1 GiB，可调）；工作区只按本次 UUID 清理，`MUST NOT` 递归删除用户目录。
- **S-07** 不自动提权、不清除只读属性；始终拒绝整理 Windows 安装目录。
- **S-08** 不实现备份、事务回滚、任务重放；日志仅供审计。
- **S-09** 界面运行摘要区分回收与永久删除的逻辑大小，不声称等于文件系统实际释放量。
- **S-10** 硬链接模式先建替代链接成功后才处理原副本；跨卷/不支持时在删除原文件前安全失败。
- **S-11** 「最新」一律指文件修改时间（mtime）；除 C-03 的平局规则外，平局按相对路径长度再按路径字典序稳定决胜。

## 3. 整理规则配置（R）

- **R-01** 规则面板五分区：解压 / 去重 / 归类 / 清理 / 安全与性能；40 项基础规则 + 高级选项层（低频规则默认折叠）；规则仅会话内生效，不落盘、不导入导出（无独立设置页）。
- **R-02** 解压保护四重上限：嵌套深度（默认 16）、单包条目数（默认 100 万）、单包展开体积（默认不限）、展开比例（默认 10000）；超限保留原包并记录原因。
- **R-03** 原压缩包处置默认跟随全局删除方式（即默认回收站）；可选保留 / 回收 / 永久删除；有跳过、失败或分卷来源不确定时强制保留。
- **R-04** 去重三类独立启停（同名 / 副本名 / 不同名同内容，默认全开）；保留规则可选最新 / 最旧 / 最大 / 最小 / 最短名称（默认最新）；重复文件默认删除（删除方式跟随全局），可选改为同卷硬链接。
- **R-05** 同名但内容不同的文件 `MUST NOT` 被自动淘汰或版本取舍，`MUST NOT` 提供相应开关（Windows 同目录不允许同名文件并存；按名称跨目录淘汰风险过高）。
- **R-06** 清理项各有独立开关与删除方式覆盖：系统附属文件（默认开）、临时/备份（默认关）、零字节（默认关）、副本后缀清理（默认开）、名称 NFC 规范化（默认开）、按内容签名修正扩展名（默认关）。
- **R-07** 扫描默认不跟随符号链接 / junction / reparse point；隐藏与系统属性文件需显式开关；排除规则为分号分隔 glob（`*` 可跨多层）。
- **R-08** Hash 工作线程数 1–16 可配（默认 2）；机械盘建议 1。
- **R-09** 归类附加项：大文件单独归类（默认关，阈值默认 1 GiB）、合并不同位置的同名目录（默认关）、消除只有一个子项的目录层级（默认关）。

## 4. 界面与交互（U）

- **U-01** 无系统边框自绘标题栏：32px 可拖动条带、右上最小化/最大化-还原/关闭、双击条带切换最大化；启动居中、不默认最大化；默认 1120×720，最小 960×620。
- **U-02** 控件分工固定：面板切换 = 下划线页签（Tab），规则分区 = 实心胶囊（Pill），窗口按钮 = CaptionButton，进度 = ProgressBar；同类新控件复用而非另写一套。
- **U-03** 进度语义：总量已知显示百分比 + 进度条 + 计数；总量未知（扫描/Hash/解压）显示不确定光带 + 实时计数（文件数/读取量/速度），`MUST NOT` 编造百分比；空闲隐藏。
- **U-04** 自绘可交互控件必须带 `accessible-role`/`accessible-label`，Tab 键序可达、聚焦有可见焦点框，空格/回车等同点击。
- **U-05** 布局随窗口缩放自适应（拉伸与 stretch），常见尺寸内不裁切、不重叠、不溢出；默认尺寸且无提示条的默认状态下「处理规则」同屏可见 9 行（出现蓝/红提示条时允许少于 9 行，列表可滚动）。
- **U-06** 文件对话框有明确默认位置：选目录从已输入目录开始。
- **U-07** PerMonitorV2 DPI manifest；图形驱动异常时可经 `launch-software.cmd` 请求软件渲染。

## 5. 代理工具（X）

- **X-01** 状态总览（只读检测）：代理环境变量（Windows 大小写不敏感合并）、Windows 系统代理（WinINET，标注注册表来源）、常见 VPN/代理进程及其监听端口（内置名单 + 端口启发式，`MUST NOT` 把 8080/8888 当代理特征端口）、虚拟网卡（TAP/Wintun/WireGuard 等特征）。
- **X-02** 网络身份：展示本机对外 IPv4、各网卡 MAC 与 IPv4、外网 IP（经公共回显服务查询，只读、不上传本机数据）；全部可一键复制。
- **X-03** 网络连接测试：测试本机能否连接互联网——对三个固定国外站点 `chatgpt.com`、`www.google.com`、`github.com` 发起 TCP 443 探测（仅用户点击时执行，不自动发起、不上传数据）；同一目标在 WSL2 发行版内独立探测（WSL2 有独立网络命名空间）；无 WSL 发行版时明确提示，不崩溃。
- **X-04** 代理配置命令参考（只展示、可复制，`MUST NOT` 自动执行、`MUST NOT` 修改系统设置）：Windows 会话/永久环境变量、WinHTTP 系统代理、Linux export / bashrc 等；**必须包含 git 代理配置片段**（`http.proxy` / `https.proxy` 的设置与取消命令，注入当前端口），可直接复制进 git 配置文件或终端执行。
- **X-05** 动态端口同步：命令参考中全部端口号由当前生效端口动态生成；界面端口可编辑，编辑或刷新后所有命令即时以最新端口重建；未指定时默认 7890；复制即生效。
- **X-06** 单项检测失败只记入该项，不中断其他项、不写全局错误、不崩溃；空列表用空态文案；「未检测到」`MUST NOT` 表述为「系统一定没有」。
- **X-07** 子进程不闪控制台窗口，输出按系统代码页正确解码（PowerShell 强制 UTF-8）；检测在后台线程执行，不阻塞界面与关窗；不做结果缓存，进入页面自动刷新一次，检测期间显示进行中状态且刷新按钮禁用。

## 6. 引擎与发布（E）

- **E-01** 7-Zip 引擎只从官方 release 获取（固定版本、校验上游 SHA-256、拒绝镜像）；引擎可执行文件不进 git、不进发布包。
- **E-02** 引擎解析顺序固定：EXE 同目录 `resources/7zip` → 已释放的内嵌副本 → 从 EXE 释放；逐文件校验后才使用；已存在文件不覆盖（保持官方可替换性）。
- **E-03** 发布包必须保留 `licenses/`、`NOTICE` 与上游源码压缩包（许可证合规）；打包过程对引擎泄漏做 fail-closed 检查。
- **E-04** 发布经手动触发的 CI 工作流产出便携 ZIP；打包过程中未执行的阶段必须如实标注 `NOT RUN`。
- **E-05** 构建机缺引擎时构建不失败（仅不内嵌）；运行期无引擎时解压必须给出明确错误，`MUST NOT` 静默跳过；引擎只能按 E-02 的固定顺序获得，不提供指定引擎路径的参数。
