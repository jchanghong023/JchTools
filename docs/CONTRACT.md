## 0. 产品定位（P）

- **P-01** JchTools 是用户个人使用的 Windows 本地工具箱；「递归解压」「目录整理」都只是工具名称，`MUST NOT` 用作产品名。
- **P-02** 工具经统一注册表（id / 名称 / 类别 / 摘要）接入，侧栏导航只遍历注册表；不设空占位分类。当前两个工具：递归解压（文件类）、目录整理（文件类）。
- **P-03** 软件完全离线：`MUST NOT` 发起任何网络请求，`MUST NOT` 上传文件、日志或路径。
- **P-04** 界面中文；浅/深主题跟随系统并可在「关于」页切换；颜色一律走统一设计令牌。
- **P-05** 个人使用交付，两种形态并列：① 安装包——安装到当前用户目录（不要求管理员权限/UAC），自动创建桌面快捷方式与开始菜单入口，并在系统「应用与功能」提供卸载项；② 便携 ZIP。`MUST NOT` 要求代码签名与公开分发验收。
- **P-06** 范围边界：不提供命令行界面（全部操作经图形界面完成）；不提供整理报告及任何形式的报告或日志导出（含 CSV）。
- **P-07** 平台支持范围仅为 Windows：构建、测试、验证与 CI 流水线只在 Windows 上运行；`MUST NOT` 为其他平台维护测试入口、验证阶段或流水线 job。
- **P-08** 不防御处理期间的并发外部改动：扫描、分析、执行全程假定文件与目录不被其他程序修改、删除、改名或替换；`MUST NOT` 为此做变化检测、二次快照比对、冲突重算或并发保护。处理期间确有外部改动时结果不作保证，该情形不计入需求范围。

## 1. 递归解压（X）

定位：只做解压。选定目录后把目录内全部压缩包递归解开；成功跑完后，所选目录（除「解压失败」子目录外）`MUST NOT` 残留任何压缩包。

- **X-01** 职责边界：只解压——不去重、不归类、不做垃圾清理；支持格式以捆绑 7-Zip 引擎实际能力为准（候选后缀 7Z/ZIP/RAR/TAR/GZ/BZ2/XZ/ZST/TGZ/CAB/ISO/WIM 等）。
- **X-02** 流程为一段确认：选目录 → 调整规则 → 点「开始解压」→ 弹一次确认（告知发现的压缩包数量、就地解压去向、成功原包将被直接永久删除且不可恢复、失败原包移入「解压失败」）→ 确认后连续执行至结束；无计划审核环节。
- **X-03** 就地解压：每个压缩包解到它所在的位置，不集中到统一输出目录。
- **X-04** 解压冲突（目标位置已有同名文件）默认自动裁决：保留修改时间（mtime）最新者；mtime 相同保留体积较大者。被淘汰的旧文件先直接永久删除再放置新文件；冲突自动裁决算正常结果，不算失败。
- **X-05** 成功完全解开的原压缩包直接永久删除（不经回收站、不可恢复）。
- **X-06** 未能完全解开的原压缩包（损坏、加密、格式不支持、分卷不全、触防护上限、含被拒绝的危险条目）移入所选目录根下的「解压失败」子目录，并记录每个包的失败原因，界面可查。
- **X-07** 重跑排除：再次解压时默认跳过「解压失败」子目录内的包，不重复尝试；用户手动补救后将包移出该目录，下次扫描自然重试。
- **X-08** 解压安全防护（默认值，可在规则面板调整）：
  - 嵌套压缩包继续解（如 ZIP→TAR），最大嵌套层数默认 16，超限包移入「解压失败」并记录原因；
  - 单包条目数上限默认 100 万；最大展开比例（解出体积÷包体积）默认 10000，0 为关闭；
  - 单包与单文件展开体积默认不限（支持 TB 级）；解压前与运行中持续检查磁盘剩余空间，始终预留默认 1 GiB，不足则保留源包并报错停止；
  - 危险条目拒绝或跳过、`MUST NOT` 写入磁盘：路径穿越（`../` 逃出目标）、绝对路径、符号链接条目、加密条目、无法解码的文件名；
  - 先解到同卷独立临时工作区（随机标记），整包成功后才合入正式位置；中断或取消不留下半新半旧状态；工作区只按本次标记清理，`MUST NOT` 递归删除用户目录。

## 2. 目录整理（C）

定位：只做整理（去重、归类、清理），`MUST NOT` 解压；假定压缩包已由「递归解压」处理。

- **C-01** 流程两段式：选目录 → 调整规则 → 启动「分析」——分析阶段只读扫描与计算，`MUST NOT` 改动任何文件 → 生成分页计划（逐项可勾选/取消）→ 第二次确认后执行。
- **C-02** 去重判定：三类名称关系——同名与副本名（`(1)`/`- Copy`/`副本`后缀）默认参与，不同名默认关闭（可手动开启）；只有内容完全相同（整文件哈希一致）才判定重复，删除前 `MUST NOT` 重读文件内容做逐字节复核或任何形式的二次内容比对（同 S-03 / C-12）。同名但内容不同的文件 `MUST NOT` 被自动淘汰，也 `MUST NOT` 提供此类开关。
- **C-03** 重复组保留者：默认保留修改时间（mtime）最新者；mtime 相同按相对路径长度、再按路径字典序稳定决胜。
- **C-04** 其余副本默认直接永久删除（同 S-02）；可选改为同卷硬链接模式（先建链接成功后才处理原副本，跨卷或不支持时在删除原文件前安全失败）。
- **C-05** 归类默认按大类（视频、文档、图片等；未匹配入「其他」），可选按扩展名 / 按修改日期（年/月）/ 按自定义扩展名规则 / 不归类；分类目录默认直接建在所选目录根下（可选先建统一输出目录）；分类目录内默认保留原相对路径（可选扁平归类，同名自动改名）；重复执行幂等，分类目录不嵌套自身。
- **C-06** 归类附加项（默认全关）：大文件单独归类（阈值默认 1 GiB）、合并不同位置的同名目录、消除只有一个子项的目录层级。
- **C-07** 清理——空目录：整理结束自动清理（默认开），自底向上仅删除实际为空的目录与空目录链，`MUST NOT` 递归删除有内容的目录。
- **C-08** 清理——垃圾与文件名（各有独立开关与删除方式覆盖，默认跟随全局删除方式）：系统附属文件（Thumbs.db/.DS_Store/desktop.ini/__MACOSX/._*，默认开）；临时与备份（.tmp/.temp/.bak/Office ~$，默认关）；零字节文件（默认关）；去重后副本后缀清理（去掉保留者的 `(1)`/`- Copy`/`副本` 后缀，中文「副本」紧贴文件名也识别，默认开）；文件名 NFC 规范化+合并连续空白（默认开，不删正常字符）；按内容签名修正错误扩展名（默认关，改名列入计划可见）。
- **C-09** 「解压失败」子目录默认整个排除：不参与去重、归类、清理，运行时明确提示已跳过。
- **C-10** 运行规则：相同规则重复整理结果幂等（用户手工改动或规则切换才会产生新计划）；改变规则或目录后「执行」失效，必须重新分析；不做处理期变化检测（同 P-08），执行阶段按分析期记录直接执行；`MUST NOT` 以覆盖方式处理目标已存在的情形（同 S-01）；用户主动取消不算失败、不报错，取消在安全边界生效；无断点恢复、无任务重放。
- **C-11** 状态可见：任务状态（分析中/计划就绪/执行中/完成/失败/已取消）与计划行状态（待执行/已执行/已跳过/已取消勾选/执行失败）用中文如实展示；仅「计划就绪」状态的任务可执行；翻页按钮仅在上/下一页真实存在时可用；切换类型筛选回到第一页。
- **C-12** 哈希唯一性：整理过程中每个文件的内容哈希只计算一次，`MUST NOT` 为分阶段筛选重复读取同一文件内容，`MUST NOT` 做二次哈希或采样哈希；候选范围只依据扫描期已获得的信息（大小与名称关系）确定，完整哈希在一次遍历内完成；执行阶段 `MUST NOT` 读取文件内容，只做改名与删除。同尺寸是内容相同的必要条件，本约束不降低 C-02 的检出范围。
- **C-13** 跨运行哈希复用：任务库状态目录维护按（文件标识、大小、修改时间）索引的哈希缓存，记录本次运行已算出的整文件哈希；后续运行的候选文件三者均与缓存一致时 `MAY` 直接复用该哈希、不再读取文件内容，任一不同或无缓存记录时 `MUST` 完整重算。本条确立「三者未变即内容未变」的跨运行信任假设（P-08 只覆盖单次运行期间），不防御以保留时间戳方式替换文件内容的行为；文件标识退化到无法区分不同文件（如部分文件系统恒报索引号 0）时 `MUST NOT` 复用。缓存只是分析加速：判定依据仍是 C-02 的整文件哈希一致，检出范围不得因缓存扩大或缩小。

## 3. 数据安全不变量（S）——最高优先级，与其他需求冲突时优先

- **S-01** 任何移动/改名 `MUST NOT` 带覆盖语义；旧文件先按已授权规则处理，再放置新文件。
- **S-02** 删除一律为永久删除、不经回收站：删除方式只在「保留」与「永久删除」之间选择，`MUST NOT` 提供回收站选项，也 `MUST NOT` 提供任何降级开关；被删除的文件不可由本软件恢复，任务确认时 `MUST` 明确告知；删除前 `MUST` 完成已授权的安全校验（同 S-01 / S-03），用户取消后 `MUST NOT` 继续任何删除。
- **S-03** 去重必须整文件哈希一致才判定重复；删除前 `MUST NOT` 重读文件内容做逐字节复核或任何形式的二次内容比对（同 C-02 / C-12）。
- **S-04** 扫描默认不跟随符号链接/junction/reparse point（防环、防逃出所选目录）；隐藏与系统属性文件需显式开关才纳入；排除规则为分号分隔 glob（`*` 可跨多层）。
- **S-05** 不自动提权、不清除只读属性；始终拒绝整理 Windows 安装目录，无开关可放开。
- **S-06** 运行结束摘要按逻辑大小报告已永久删除的项，`MUST NOT` 声称等于文件系统实际释放量。
- **S-07** 不实现备份、事务回滚、断点恢复、任务重放；日志仅供界面审计（最近 300 条，最新在上），不导出。
- **S-08** 「最新」一律指文件修改时间（mtime）；冲突平局见 X-04（体积大者），去重平局见 C-03（路径长度→字典序）。

## 4. 规则面板（R）

- **R-01** 规则面板按工具显示相关分区（递归解压：解压与安全性能项；目录整理：去重/归类/清理与安全性能项）；低频规则默认折叠进「高级选项」层；规则仅会话内生效，`MUST NOT` 落盘保存、不提供导入导出（无独立设置页）。
- **R-02** 已确认的默认值即日常行为，各项保留可切换选项：解压冲突策略（逐次询问可应用后续全部/覆盖/跳新/保留较大/两份保留重命名，默认见 X-04）；原包处置（保留/永久，默认见 X-05）；去重三类独立启停；保留规则（最新/最旧/最大/最小/最短名称，默认见 C-03）；重复处置（删除/同卷硬链接，默认见 C-04）；分类方式（见 C-05）；清理六项开关（见 C-08）。
- **R-03** 扫描与性能：默认递归包含全部子目录（可关）；哈希并行线程 1–16 可配，默认 6（机械盘建议 1）；磁盘预留空间默认 1 GiB 可调（见 X-08）。
- **R-04** 规则或目录改动后，既有分析结果与「执行」按钮失效，必须重新分析（同 C-10）。

## 5. 界面与交互（U）

- **U-01** 自绘无边框标题栏：条带可拖动、双击切换最大化，右上最小化/最大化-还原/关闭；启动居中、不默认最大化；默认 1120×720，最小 960×620。
- **U-02** 控件分工固定并全软件复用：面板切换=下划线页签（Tab）、规则分区=实心胶囊（Pill）、窗口按钮=CaptionButton、进度=ProgressBar；同类新控件复用而非另写一套。
- **U-03** 进度语义：总量已知显示百分比+进度条+计数；总量未知（扫描/哈希/解压）显示不确定光带+实时计数（文件数/读取量/速度），`MUST NOT` 编造百分比；空闲隐藏。
- **U-04** 自绘可交互控件必须带 `accessible-role`/`accessible-label`，Tab 键序可达、聚焦有可见焦点框，空格/回车等同点击。
- **U-05** 布局随窗口缩放自适应，常见尺寸内不裁切、不重叠、不溢出；默认尺寸且无提示条的默认状态下「处理规则」同屏可见 9 行（出现提示条时允许少于 9 行，列表可滚动）。
- **U-06** 提示两级：信息蓝条、错误红条，可分别关闭；用户取消 `MUST NOT` 报成错误。
- **U-07** 文件对话框有明确默认位置：选目录从已输入目录开始。
- **U-08** PerMonitorV2 DPI manifest；图形驱动异常时可经 `launch-software.cmd` 请求软件渲染。
- **U-09** 运行中关闭窗口必须弹「停止任务并关闭」确认，且始终盖在其他弹窗（含解压冲突询问）之上。
- **U-10** 运行日志最新在上、界面仅保留最近 300 条；`MUST NOT` 提供导出（同 P-06）。
- **U-11** 切换工具时跨工具共用的界面状态不得串用：面板页签回到该工具默认面板（「处理规则」），`MUST NOT` 停留在当前工具不存在的面板上。

## 6. 引擎与发布（E）

- **E-01** 7-Zip 引擎只从官方 release 获取（固定版本、校验上游 SHA-256、`MUST NOT` 用镜像）；引擎可执行文件不进 git、不进发布包。
- **E-02** 引擎解析顺序固定：EXE 同目录 `resources/7zip` → 已释放的内嵌副本 → 从 EXE 释放；逐文件校验后才使用；已存在文件不覆盖（保持官方可替换性）。
- **E-03** 发布包必须保留 `licenses/`、`NOTICE` 与上游源码压缩包（许可证合规）；打包过程对引擎泄漏做 fail-closed 检查。
- **E-04** 发布经手动触发的 CI 工作流产出两种产物：安装包（EXE，见 P-05）与便携 ZIP；打包过程中未执行的阶段必须如实标注 `NOT RUN`。
- **E-05** 构建机缺引擎时构建不失败（仅不内嵌）；运行期无引擎时解压必须给出明确错误并停止，`MUST NOT` 静默跳过；引擎只能按 E-02 固定顺序获得，不提供指定引擎路径的参数。
