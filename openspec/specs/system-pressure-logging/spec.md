# system-pressure-logging Specification

## Purpose
为 JchTools 提供简单、独立的系统压力记录能力，每两秒将整机 CPU、内存和每块物理磁盘的负载优先写入 D 盘根目录，D 盘不存在时使用系统临时目录。采集在关闭 GUI 后继续运行，以单文件循环方式保留最近二十分钟的数据，不引入图表、可配置采集策略或开机自启。

## Requirements

### Requirement: SPL-01

JchTools MUST 提供独立「系统压力记录」页面，包含开始记录、停止记录、实际运行状态及按 SPL-04 选择的实际输出路径。功能 MUST 手动启动，不依赖其他工具，不增加图表、周期、路径或保留时长配置。普通打开 GUI 不开始记录，Windows 重启后不自动恢复。

#### Scenario: SPL-01 独立入口与手动启动
- **WHEN** 用户打开 JchTools 并进入「系统压力记录」页面，且尚未启动采集
- **THEN** 显示未运行状态、开始和停止入口及实际输出路径；未点击开始前不采集、不写入，不要求先运行其他工具

#### Scenario: SPL-01 系统重启
- **WHEN** Windows 重启后用户重新打开 GUI
- **THEN** 不自动恢复记录，由用户再次点击开始；不为该功能新增开机自启

### Requirement: SPL-02

开始记录后，系统 MUST 由独立后台持续采集，不依赖 GUI 存活。关闭 GUI MUST 不停止记录；重开 GUI MUST 显示真实状态并能停止既有采集，不重复启动采集。主动停止成功后 MUST 不再采集或更新数据文件，并保留已输出文件。

#### Scenario: SPL-02 关闭与重新打开 GUI
- **WHEN** 正在记录时用户关闭 GUI，随后重新打开
- **THEN** 关闭期间仍按每 2 秒的周期记录；重开显示正在运行并可停止，不产生第二个采集实例或重复记录

#### Scenario: SPL-02 主动停止
- **WHEN** 用户点击停止记录且后台确认停止成功
- **THEN** 状态显示已停止，不再追加或改写采集数据，已有 CSV 文件保留

### Requirement: SPL-03

系统 MUST 每 2 秒采集一次，记录采样时间、整机 CPU 使用率、物理内存使用率，以及每块物理磁盘的编号、活动时间百分比、读取速度和写入速度。使用率单位为百分比，读写速度单位为 MiB/s。CPU 和磁盘负载对应最近采样间隔，内存对应采样时状态；指标无法取得时 MUST 明确标示不可用，不伪造成零。同一物理磁盘的多个分区不得重复计为多块磁盘。

#### Scenario: SPL-03 采集与磁盘口径
- **WHEN** 后台正在运行且完成一个采样周期
- **THEN** 输出带时间的 CPU、内存及每块物理磁盘的上述指标；磁盘指标反映 I/O 繁忙程度和吞吐，不用空间占用率替代；同盘多个分区只对应一个磁盘统计对象

#### Scenario: SPL-03 指标不可用
- **WHEN** 本次采样无法取得某项指标，包括尚无足够的间隔数据
- **THEN** 该指标明确标示不可用，仍可区分真实的零负载与采样缺失，不生成虚假负载值

### Requirement: SPL-04

系统 MUST 优先输出可读取的 CSV 至 `D:\JchTools-performance.csv`；仅当 D 盘不存在时，使用系统临时目录下的 `JchTools-performance.csv`，GUI 显示实际路径。CSV MUST 包含字段说明及单位，仅维护一个循环更新的数据文件；每次更新保留最近 20 分钟的已有采样并淘汰过期采样，不分卷、不无限追加、不在满 20 分钟后停止。选定路径不可写或更新失败时 MUST 明确报错，不宣称记录正常，不因写入失败切换目录或自动提权。采集和输出 MUST 本地完成，不联网或上传数据。

#### Scenario: SPL-04 D 盘存在
- **WHEN** 用户开始记录且 D 盘存在
- **THEN** 输出到 `D:\JchTools-performance.csv`，界面显示该路径，不使用系统临时目录

#### Scenario: SPL-04 D 盘不存在
- **WHEN** 用户开始记录且 D 盘不存在
- **THEN** 输出到 Windows 系统临时目录下的 `JchTools-performance.csv`，界面显示所选绝对路径，仍只维护一个循环文件

#### Scenario: SPL-04 不足 20 分钟
- **WHEN** 本轮记录尚未达到 20 分钟且完成采样
- **THEN** 每次采样后更新固定 CSV，可读取已有数据，不等待窗口满后才输出，不生成其他历史数据文件

#### Scenario: SPL-04 循环保留
- **WHEN** 持续记录超过 20 分钟并更新文件
- **THEN** 固定 CSV 保留最近 20 分钟内的已有采样，超过窗口的采样被淘汰，后续采集继续，数据不累计到第二个文件

#### Scenario: SPL-04 选定路径写入失败
- **WHEN** 开始记录或后续更新时因权限不足、文件占用或其他写入错误无法更新所选 CSV
- **THEN** 明确提示实际路径及失败原因，状态不得仍宣称记录正常，不因写入失败改到其他目录输出，不自动请求提权
