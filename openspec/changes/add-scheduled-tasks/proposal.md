# Proposal

## Why

为 JchTools 增加简单易用的个人定时任务工具，按分钟或小时周期执行用户命令，关闭 GUI 后仍能运行，重新打开即可管理和查看日志。

现有工具注册表尚无定时任务；截图服务已有独立于 GUI 的后台运行方式，可沿用其使用体验，不引入企业级调度能力。

## What Changes

1. **后台运行**：后台负责调度和执行；关窗不停止，重开不重复启动；配置、启用状态和执行历史持久保存。
2. **任务配置**：名称、命令、工作目录、正整数分钟／小时周期。工作目录支持手工输入和「浏览」选择文件夹，显示完整路径。高级设置仅含 Shell、环境变量、超时，不使用 Cron。
3. **管理界面**：独立「定时任务」入口，显示名称、周期、启用状态、当前状态、上次结果、下次执行时间；支持新增、编辑、删除、启用／禁用、立即执行、停止本次执行、查看日志。
4. **执行规则**：首次启用等待一个周期；同任务不并发，忙时跳过、不积压，停机漏跑不补跑。禁用只停止后续调度，编辑从下次执行生效；停止或超时终止关联子进程，异常退出的未完成记录标记「中断」。
5. **执行日志**：每任务最近 100 次实际执行，包含手动执行；记录开始／结束时间、耗时、触发方式、状态、退出码、stdout、stderr、当次命令和工作目录。支持运行中查看、复制和导出；单次日志默认最多 1 MB，超限保留尾部并提示截断，淘汰历史时同步清理日志文件。

### Confirmed Decisions

- 允许用户命令联网，调度服务自身不因此联网或上传日志。
- 运行中禁止删除，提示先停止本次执行。
- 修改周期保留已排定的下一次触发时间，此后使用新周期。
- 个人工具，简洁易用。只保留上述需求，不规定额外的 Shell 扩展、自启／托盘方案、复杂恢复流程或新增配置项。未决问题：无。

## Capabilities

### New Capabilities

- `scheduled-tasks`：后台周期执行、任务配置与管理、执行控制和有界历史日志。

### Modified Capabilities

- `application-contract`：P-02 登记新工具；P-03 为用户命令联网增加限定例外；P-06 / U-10 为本工具日志导出增加限定例外；U-09 明确关窗不停止定时任务。其余规则保留。

## Impact

- 涉及 GUI 注册与页面、后台执行、本地配置与历史、关联子进程控制及日志。现状依据为 `crates/gui/src/registry.rs`、`optional/snap-ocr-worker/src/service.rs` 和 `crates/codeagent/src/codeagent.rs`；现有后台测试不代表定时任务已实现。
- 定时任务输出是本工具的执行记录，不混入 P-10 去敏诊断日志；不改变其他工具的联网、日志、退出及文件处理规则。
- 后续功能交付同步 README 功能与需求入口、AGENTS.md 功能域说明及 `requirements_registry` 登记；本轮不修改这些文件。
- 验收范围为上述五组需求及已确认规则。本轮只创建提案和增量规格，不修改主规格或产品代码，不创建设计／任务产物，不执行软件验证、同步或归档。
