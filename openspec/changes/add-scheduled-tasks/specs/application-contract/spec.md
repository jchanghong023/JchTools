# Spec Delta

## MODIFIED Requirements

### Requirement: P-02

JchTools MUST 遵守本条行为：工具经统一注册表（id / 名称 / 类别 / 摘要）接入，侧栏按注册表显示真实工具，不设空占位分类。

#### Scenario: P-02 完整行为与适用边界
- **WHEN** 用户启动或使用 JchTools、执行文件任务或进行相应交付验收，且涉及本条规定的条件
- **THEN** 工具经统一注册表（id / 名称 / 类别 / 摘要）接入，侧栏按注册表显示真实工具，不设空占位分类。保留的八个工具为递归解压、目录整理、MD 整理、转 Markdown、Git 工具、截图 OCR、CodeAgent、定时任务；递归解压和目录整理归「文件」，MD 整理、转 Markdown 和截图 OCR 归「文档」，Git 工具、CodeAgent 和定时任务归「开发」。各工具保持独立，既有六工具关系按 H-03，CodeAgent 按 CA 分区，定时任务按 ST 分区；转换、截图的功能边界分别由 T / O 分区维护，共享组件的独立「设置」入口按 XB-20 管理，不将内部后台进程作为另一套 GUI 产品。

### Requirement: P-03

JchTools MUST 遵守本条行为：离线处理：所有文件处理功能离线可用，程序自身不得发起网络请求，不得上传文件、日志或路径；仅本条明确列出的例外除外。

#### Scenario: P-03 完整行为与适用边界
- **WHEN** 用户启动或使用 JchTools、执行文件任务或进行相应交付验收，且涉及本条规定的条件
- **THEN** 离线处理：所有文件处理功能离线可用，程序自身不得发起网络请求，不得上传文件、日志或路径。用户主动点击关于页官网链接时，允许交由系统浏览器打开，不附加用户文件、路径或日志信息；该例外不允许后台联网或自动打开网页。
  - 关于页外开仅允许发布时确定的项目官网 `https://` 或 `http://` URL，不接受文件内容、路径或日志拼成 URL，不调用 `file:`、脚本或自定义协议。目标网址须在关于页可辨识；具体域名是发布身份信息，不影响离线处理规则。
  - Git 工具例外（仅限 G 分区）：用户在 Git 工具页主动启动任务后，允许通过 git 命令访问所选仓库当前分支已配置的 upstream 远端（fetch / push 及其合并所需网络访问由 git 自身完成，见 G-08 / G-10）；不向 upstream 之外的任何地址发起请求，不上传本工具的日志、配置或用户路径。任务未启动或停止后不发起任何网络访问。该例外不放宽其他工具与其他分区的离线要求。
  - 音频转写可选资产下载例外（仅限 T-05 / T-06 / T-21 / XB 分区）：仅用户在统一设置页明确发起后，允许下载随包 Xberg 引擎清单声明匹配的 FFmpeg 及其必要 DLL / 许可、SenseVoice INT8、Silero VAD 及配套模型数据，装入同一共享运行目录；不下载或替换共享 Xberg 引擎，不替换已有有效的随包 DLL，不将 sherpa-onnx、共享 ONNX Runtime 等其他既定随包运行依赖改为下载。来源、选版、精确版本、大小与摘要校验按 XB-10，下载进度、失败、取消、重试及有效资产和配置保护按 XB-20 / XB-21，资产边界、路径安全及事务保护按 XB-27，网络出口与 TLS 按 P-09。媒体所需可选资产未就绪时提示用户到设置页主动下载，不因处理媒体文件静默下载。录音、会议视频仅指既有音轨转写，不增加录音采集、会议功能、视频画面理解或 T-08 / T-19 之外的格式。
  - 截图 OCR、文档与图片转换所需引擎、两套独立 OCR 模型与字典及运行依赖按 P-05 / XB-27 随包提供，结果窗字体和许可证仍按 O-05 内置于随包截图服务程序；安装或解包后自动定位同一共享运行目录，无需另行下载或手填目录。普通启动、切换 tab、截图及转换均不得自动联网下载或更新，不上传截图、文字、用户文件、路径或日志；未下载 FFmpeg 和音频模型不影响共享 worker、截图服务的正常启动以及截图、文档/图片 OCR、jchocr 或旧工具。缺失或损坏的随包文件须提示从安装包修复、重装或重新解包，不引导另行下载截图或文档组件。
  - jchocr 图片 URL 例外仅按 O-34：调用方显式提供 HTTP(S) 图片 URL 时允许下载该图片及其 HTTP(S) 重定向目标，下载内容只驻内存并交本地 OCR；不上传图片、文字或日志，不自动下载 Xberg，不放宽其他工具的联网权限。
  - 定时任务例外仅限 ST 分区：允许用户配置并由周期或手动触发的命令及其关联子进程联网；调度服务自身不因此新增联网、下载或日志上传行为，不放宽其他工具的离线规则。

### Requirement: P-06

JchTools MUST 遵守本条行为：除 O-33～O-37 的 jchocr 图片 OCR 命令外，不提供命令行界面，其他用户操作经图形界面完成；不提供整理报告及任何形式的报告或日志导出，包括 CSV，仅 ST-05 规定的定时任务执行日志导出除外。

#### Scenario: P-06 完整行为与适用边界
- **WHEN** 用户启动或使用 JchTools、执行文件任务或进行相应交付验收，且涉及本条规定的条件
- **THEN** 除 O-33～O-37 的 jchocr 图片 OCR 命令外，不提供命令行界面，其他用户操作经图形界面完成；不提供整理报告及任何形式的报告或日志导出，包括 CSV，仅 ST-05 规定的定时任务执行日志导出除外。jchocr 的 stdout 正文及 JSON 结果是本次识别的直接返回值，不是历史报告或日志导出；不提供 MCP。
  - 截图 OCR 的内部测试入口与工作进程协议不作为用户命令行产品。正文复制按 O-22；仅本功能的用户主动复制去敏内存诊断按 O-30，不能含截图、识别文字或用户路径，不构成运行日志文件或报告导出，也不放宽其他工具的限制。
  - 定时任务仅由用户主动导出其保留的执行日志；执行用户命令不构成新增 JchTools 用户 CLI，不开放其他工具的报告、日志或 P-10 诊断文件导出。

### Requirement: U-09

JchTools MUST 遵守本条行为：主窗口有转换、解压、整理、MD 或 Git 等在途任务时，关闭前必须弹出「停止任务并关闭」确认，始终位于其他弹窗之上；确认后按各工具安全边界停止，转换按 T-23 尽快取消当前文件，停止完成后关闭窗口。定时任务后台及其执行不纳入此关窗停止范围。

#### Scenario: U-09 完整行为与适用边界
- **WHEN** 用户启动或使用 JchTools、执行文件任务或进行相应交付验收，且涉及本条规定的条件
- **THEN** 主窗口有转换、解压、整理、MD 或 Git 等在途任务时，关闭前必须弹出「停止任务并关闭」确认，始终位于其他弹窗之上；确认后按各工具安全边界停止，转换按 T-23 尽快取消当前文件，停止完成后关闭窗口。这些任务不转为关窗后继续执行的后台任务。仅截图后台运行时，关闭主窗口无需确认停止该后台；关闭或终止 GUI 不取消截图任务，不移除托盘、热键或常驻模型。原有截图及共享 Xberg 后台的主动退出由托盘按 XB-23 管理；CodeAgent 的独立常驻与维护退出仍按 CA-05 / CA-08，不纳入文件任务关闭范围。定时任务按 ST-01 / ST-04 独立执行；关闭或终止 GUI 不停止其后台、本次执行或后续调度，重开不重复启动调度；不改变既有工具的退出职责。

### Requirement: U-10

JchTools MUST 遵守本条行为：运行日志最新在上，界面仅保留最近 300 条，不提供导出；定时任务的执行记录及输出日志单独按 ST-05 管理。

#### Scenario: U-10 完整行为与适用边界
- **WHEN** 用户启动或使用 JchTools、执行文件任务或进行相应交付验收，且涉及本条规定的条件
- **THEN** 运行日志最新在上，界面仅保留最近 300 条，不提供导出。递归解压另提供本次任务的失败项分页列表：每个失败包或 X-10 卷集对应一项，至少显示原路径、失败原因和隔离后位置；隔离失败时显示隔离失败原因与未移动的源项位置，不得把隔离失败写成已隔离。列表显示失败项总数，所有失败项均可翻页查询，超过 300 项也不得截断；只在对应页真实存在时启用翻页按钮。运行中可查看已经发生的失败，任务结束或取消后仍可查看本次已产生的失败明细，直至启动下一次解压任务或退出程序；切换工具不清空该列表。用户取消本身不计为失败，源包清理失败按 X-05 单独标明阶段，不冒充坏包。列表只用于查看处理结果，不增加解压前计划审核、不提供导出、不要求跨运行保存。
  - 尚无本次解压结果时显示明确空态，不以持续加载提示冒充正在处理；空列表的标题与说明紧凑排列在内容区顶部，分页操作保留在底部。已关联且无失败项的任务明确显示没有失败项，不与尚无结果混淆。
  - 截图 OCR 不新增截图历史或内容审计；临时结果、隐私与去敏内存诊断分别按 O-20 / O-29 / O-30。P-10 的应用诊断日志只记录允许的运行元信息，不包含截图或识别文字。
  - 运行日志支持窗口内展开（2026-10-10 用户确认）：目录整理、递归解压、MD 整理、Git 工具及转 Markdown 的日志标题栏统一提供「放大」。点击后以主窗口内的大面板覆盖主要内容区，支持滚动、选择与复制；任务不中断，日志继续实时更新。点击「还原」或按 Esc 返回原布局，不清空日志，最新在上、最近 300 条及不提供导出的规则不变。展开层不得遮住关闭任务的安全确认框。
  - 定时任务每任务保留最近 100 次实际执行及对应输出日志，支持运行中查看、复制和主动导出，容量及淘汰按 ST-05；不使用界面 300 条运行日志代替执行历史，也不放宽其他工具的日志限制。
