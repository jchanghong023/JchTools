# Spec Delta

## MODIFIED Requirements

### Requirement: XB-23

JchTools MUST 遵守本条行为：常驻后台在系统通知区域提供统一托盘入口，可打开主界面、设置及截图，并提供明确的「退出后台服务」。

#### Scenario: XB-23 完整行为与适用边界
- **WHEN** 应用管理共享 Xberg、其资产与配置或提交跨场景推理请求，且涉及本条规定的条件
- **THEN** 常驻后台在系统通知区域提供统一托盘入口，可打开主界面、设置及截图，并提供明确的「退出后台服务」。关闭 GUI 仅关闭界面；用户主动结束后台通过托盘执行，退出时停止接受新任务，在各任务原有安全边界结束在途处理后释放截图资源并终止本应用拥有的共享 Xberg，不保留孤立进程，不操作用户自行启动的其他 Xberg。仍有任务时先明确提示并确认停止，等待过程可见，不静默强杀。托盘主动退出后，仍打开的 GUI 不立即自动重启服务；下次重新打开 GUI 才按 XB-22 自动启动。本条规定截图及共享 Xberg 后台的退出，不从本条自动扩张其他独立工具的退出职责。
