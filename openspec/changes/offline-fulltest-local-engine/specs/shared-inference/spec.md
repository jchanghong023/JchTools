# Spec Delta

## MODIFIED Requirements

### Requirement: XB-10

JchTools MUST 遵守本条行为：全部 Xberg 功能使用同一个运行目录，获取与选版以本条为唯一权威。

#### Scenario: XB-10 完整行为与适用边界
- **WHEN** 应用管理共享 Xberg、其资产与配置或提交跨场景推理请求，且涉及本条规定的条件
- **THEN** 全部 Xberg 功能使用同一个运行目录，获取与选版以本条为唯一权威。JchTools 打包时选择当时最新的 Xberg 正式发布版本，锁定精确 tag、正式来源、资产大小与 SHA-256，按发布清单校验归档及成员，并将该记录随包交付；不得因最新正式发布获取失败而静默改用旧版。安装或解包后默认使用包内版本，不在首次启动、普通启动、tab 切换、截图或处理文档及媒体文件时联网查询、下载或升级。主包与音频转写可选资产的边界按 XB-27，不能把共享引擎或截图/文档基础运行环境留待用户另行下载。
  - 音频转写可选资产仅在用户于设置页明确发起后下载，包括随包引擎清单声明的匹配 FFmpeg 及必要配套运行库/许可、SenseVoice INT8、Silero VAD 及配套模型数据，记录精确来源、版本、大小与 SHA-256 并校验；只补充所需 FFmpeg DLL 和模型等可选成员，不替换已有效的共享引擎或既有随包 DLL，不为追逐最新版更新它们，不重复下载已有效的匹配资产。下载和安装保留归档及成员完整性、路径安全检查和事务保护，失败或取消不覆盖有效资产与配置；不混合不匹配版本，不删除旧目录或未涉及的有效资料。设置及持久化保护按 XB-20 / XB-21，资产边界及路径事务按 XB-27，网络访问遵循 P-09 的系统代理与既有 TLS 策略，不因下载对象变化修改网络安全策略。
  - JchTools 安装包与便携 ZIP 的交付验收必须验证实际包内引擎及记录的精确版本、来源与摘要，不能另下载最新版替代包内引擎作为交付证据。真实已发布物的独立对照采用对照时最新正式发布版，已存在则复用，否则按项目测试目录规则获取；记录其版本与来源，并与包内验收明确区分，不能用旧发布物冒充最新对照，也不能用最新对照替代实际交付验收。
  - fulltest 使用固定本地 Xberg 测试引擎，离线核验其来源记录、摘要、所需文件及协议兼容性，并执行实际产品链路与输出断言；不查询最新发布、不获取、下载、安装、替换或升级引擎。缺失、损坏、不兼容或无法核验时明确给出本地路径并报告 FAIL / UNVERIFIED，不静默补齐或冒报通过。独立最新发布对照仍须单独授权并按上述规则执行，不强制跟随每轮 fulltest；打包选取最新正式发布及实际交付验收规则不变。
  - 其他字体或可选资产仍按各自清单，不改变既有 7-Zip 的 E 分区规则。
