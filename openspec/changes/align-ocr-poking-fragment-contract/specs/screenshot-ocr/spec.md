# Spec Delta

## MODIFIED Requirements

### Requirement: O-25

JchTools MUST 遵守本条行为：先合并跨瓦片接缝片段，再合并同行探入式碎片，最后去除重复检测框；合并后的文字框从原始选区重新裁剪，不能拼接已识别文字代替重裁识别。

#### Scenario: O-25 完整行为与适用边界
- **WHEN** 用户使用截图 OCR、其后台、结果窗口或 jchocr 图片识别入口，且涉及本条规定的条件
- **THEN** 先合并跨瓦片接缝片段，再合并同行探入式碎片，最后去除重复检测框；合并后的文字框从原始选区重新裁剪，不能拼接已识别文字代替重裁识别。重复关系为 IoU ≥ 0.4 或交集/较小面积 ≥ 0.6，按传递关系分组，优先保留不接触内部瓦片边缘、边缘距离更大、检测分数更高的候选。接缝合并要求来自水平相邻重叠瓦片、接触相应内部边缘、垂直重叠 ≥ 0.6 且文字高度相近，不能把普通分栏间距当接缝。同行探入式碎片须为水平范围阶梯交错而非包含关系的重叠框，较小高度/较大高度 ≥ 0.65、垂直重叠比例 ≥ 0.6，水平重叠宽度同时 ≥ 较大字高×0.3 且 ≤ 较窄框宽×0.25，边界值包含，按传递关系合并；不要求来自不同瓦片或接触内部接缝，不合并无重叠的普通分栏。确定性细则见附录 B。

#### Scenario: O-25 同瓦片探入式碎片先合并再去重
- **WHEN** 同一瓦片内两个未接触内部接缝的检测框分别为 `(20,20)-(220,40)` 和 `(210,20)-(410,40)`
- **THEN** 两框虽未达到重复阈值，仍按同行探入式碎片合并为 `(20,20)-(410,40)`，由原图重裁识别；不得把它们误当作必须来自不同瓦片的接缝片段。

#### Scenario: O-25 不满足探入条件的独立候选
- **WHEN** 两框不满足同行探入式碎片的任一条件，包括无水平重叠、包含关系、高度或垂直重叠不足、水平重叠宽度超出规定范围
- **THEN** 不因本合并规则改变候选，仍按原接缝合并及重复阈值处理；不得把独立分栏或本应由去重判定的包含框强行并成一框。

#### 确定性附录 B 增量

同行探入式碎片合并在接缝合并后、去重前执行；高度比 ≥ 0.65、垂直重叠比例 ≥ 0.6，水平范围须阶梯交错而非相互包含；水平重叠宽度在 [较大字高×0.3, 较窄框宽×0.25] 闭区间内。按传递关系分组，不限制来源瓦片或接缝接触；成员整体包围框取并集，检测分数取最大值，并在成员瓦片并集矩形上重算内部边缘量。合并结果从原图重裁，不拼接识别文字；无重叠分栏不合并。两类合并仍沿用既有候选排序、来源瓦片及边缘量语义，不改变原有接缝条件或重复阈值。
