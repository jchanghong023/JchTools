# Proposal

## Why

用户反馈 Git 工具没有使用 Windows 设置中的系统代理；截图中的 `127.0.0.1:7890` 仅是示例，不是地址或端口限制。现行 G-17 及 P-09 明确禁止为 Git 注入 Windows 系统代理，与本次用户要求冲突，需要先修改需求。

批准状态：已批准。2026-10-29 用户选择「Git 显式配置优先，缺省用系统代理」，并明确要求「修改需求，需要用系统代理」。本次仅同步需求，不表示代码已实现或功能验收通过。

## What Changes

- Git 工具的 HTTP(S) 网络操作优先保留 Git 原有配置及继承环境中适用于当前目标的显式代理或直连策略，包括显式空代理值和代理绕过规则。
- 没有适用的显式策略时，使用 Windows 当前用户已启用的手动系统代理，读取 `ProxyEnable`、`ProxyServer` 和 `ProxyOverride`；支持整体与按协议配置，以及服务器域名、IPv4、IPv6 和实际配置的端口，不限制为回环地址或固定端口。
- 系统代理例外表命中时直连；系统代理未启用或无可用端点时沿用 Git 原有行为。PAC / WPAD 不在本次范围内。
- 仅为本工具发起的 Git HTTP(S) 操作补充代理，不修改持久 Git 配置、Windows 设置或宿主进程环境，不改变 SSH 等其他传输协议。代理失败不强制直连；保留既有重试、停止和 TLS 校验行为。
- 同步 G-17、P-09 及 README 中相关说明，其他需求保持不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `git-file-publishing`：修改 G-17，增加 Windows 手动系统代理缺省行为及其优先级、例外和验收场景。
- `application-contract`：修改 P-09 对 Git 代理策略的交叉约束，不改变组件下载的代理回退或 TLS 策略。

## Impact

需求涉及 Git 的 fetch / push 网络调用和已有共享系统代理解析能力；本次不修改产品实现、测试或构建配置，不新增联网目标，不扩大 P-03 的 upstream 边界。

验收边界：后续功能验收须证明 HTTP(S) 请求实际经过配置的代理；Git / 环境显式代理及直连策略优先；系统例外表生效；系统代理关闭时不补充代理；SSH 行为不变；代理失败不转直连。非回环 IP 和域名必须纳入地址选择验收，不能只覆盖截图示例。

待确认事项：无。本次未运行产品功能测试，不宣称原有问题已经修复；提案与增量保留为变更记录，不执行归档。
