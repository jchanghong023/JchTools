# Spec Delta

## MODIFIED Requirements

### Requirement: XB-05

JchTools MUST 遵守本条行为：全部推理功能经唯一 Xberg 的本地 worker 协议（xberg worker，stdio JSON 行）提交请求。截图 OCR 仍传无损编码的原始选区；「截图并复制图片」仅执行本地图片处理和剪贴板发布，不属于推理请求，不经过 Xberg 或 OCR 推理队列，其 PNG 上限不改变 OCR 传入图像。

#### Scenario: XB-05 完整行为与适用边界
- **WHEN** 应用管理共享 Xberg、其资产与配置或提交跨场景推理请求，且涉及本条规定的条件
- **THEN** 全部推理功能经唯一 Xberg 的本地 worker 协议（xberg worker，stdio JSON 行）提交请求。截图 OCR 传未经图片复制分支减色、缩放的原始选区的无损编码图像字节（base64），不要求落盘；文档与转录传本地路径。每请求恰好一行响应，结果与请求明确关联，成功返回对应结构或文本，失败返回可分类错误；协议须支持跨场景并用，不能串错结果或将截图 OCR 排在当前文档结束之后。文档 extract 请求仅传 path，不携带 mode、模型或请求级转换配置；document.content 是引擎最终 Markdown，顶层 warnings 为 document.processing_warnings 的副本。JchTools 只执行媒体目录前缀及字节落盘，嵌入合入、去重与规范化由引擎承接，不重复处理或自行分节兜底。

#### Scenario: XB-05 复制图片不是推理请求
- **WHEN** 用户通过「截图并复制图片」快捷键完成有效选区，或修改该分支的最大图片大小
- **THEN** 本地图片处理模块直接处理该用途的选区并按 O-38～O-45 发布 PNG，不向共享 Xberg 发送请求、不占用 OCR 推理队列、不修改截图 OCR 的原始选区、模型、无损编码与识别参数；共享进程的唯一性、其他推理场景的协议、并用及取消隔离不变。

### Requirement: XB-22

JchTools MUST 遵守本条行为：GUI 先显示可交互窗口，后台异步读取配置、按 XB-09 检查资产并启动或连接当前 Windows 用户会话的单实例服务，界面不等待模型加载完成。图片复制的捕获、框选、压缩及剪贴板能力与 OCR 模型、共享推理就绪状态分别判断；不能因模型未就绪阻止图片复制可用服务的启动或连接，也不得因此虚报 OCR 已就绪。

#### Scenario: XB-22 完整行为与适用边界
- **WHEN** 应用管理共享 Xberg、其资产与配置或提交跨场景推理请求，且涉及本条规定的条件
- **THEN** GUI 先显示可交互窗口，后台异步读取配置、按 XB-09 检查资产并启动或连接当前 Windows 用户会话的单实例服务，界面不等待模型加载完成。新装自动发现包内目录，已有配置按 XB-18 / XB-21 恢复或迁移；截图基础资产就绪后自动启动并保活唯一共享 Xberg worker 与截图服务，不要求进入截图页、下载组件或再点击启动，FFmpeg 及音频模型未下载、FFmpeg DLL 缺失均不阻止这一过程及基础截图/文档路径。关闭或终止 GUI 进程不结束后台服务、Xberg、托盘、热键或截图任务；再次打开 GUI 连接原服务，不新增服务或引擎实例。引擎异常退出时明确报告受影响推理任务失败，后台恢复服务能力但不自动重放失败任务；恢复过程仍保持至多一个引擎。缺少或损坏随包资产如实显示相应能力未就绪并指引离线修复，不自动联网，不阻塞 GUI 及其他工具；音频转写可选资产未就绪仅影响媒体转录就绪状态，按 XB-20 提示主动下载。Windows 登录自启默认值仍按 O-15，不把「打开 GUI 后常驻」理解为默认开机自启。

#### Scenario: XB-22 模型不就绪时保留图片复制
- **WHEN** 截图服务程序及图片捕获、框选、压缩、剪贴板所需组件可用，但 OCR 模型未加载、加载中、加载失败或共享推理暂不可用
- **THEN** 启动或连接同一个截图服务，保持已生效的复制热键可用；选区按用途直接进入图片处理，不以 OCR 资产或模型就绪检查作为该分支前置条件。状态分别显示图片复制与 OCR 的实际可用性，模型错误和离线修复指引只限制依赖该模型的能力，不声称整个服务或图片复制不可用，也不把复制成功当作 OCR 恢复。

#### Scenario: XB-22 图片复制的后台生命周期不另起体系
- **WHEN** 主窗口关闭或被结束、随后重新打开，或用户主动通过托盘退出后台服务
- **THEN** 关闭 GUI 不取消后台正在进行的图片复制，重开连接同一个服务而不重复注册热键；主动退出仍按 XB-23 停止接收任务、确认并安全停止在途任务及释放资源，不让失效的复制任务迟到写剪贴板。图片复制不另启 Xberg 或新增独立常驻进程，托盘退出后的自动重启边界仍按 XB-23。

### Requirement: XB-24

JchTools MUST 遵守本条行为：截图 OCR 页面不提供「启动 / 重连」及用于常规启停服务的开关；自动连接、后台启动和常驻由 XB-22 / XB-23 管理。页面的截图设置区域提供 OCR 快捷键、「截图并复制图片」快捷键、最大图片大小及后台状态；Xberg 配置、随包组件检查、故障恢复和应用级设置仍统一在「设置」页。

#### Scenario: XB-24 完整行为与适用边界
- **WHEN** 用户打开截图 OCR 页面或统一设置页
- **THEN** 截图 OCR 页面保留原 OCR 快捷键设置和后台服务状态，增加「截图并复制图片」快捷键及「最大图片大小」，后者显示 `1 KB = 1000 字节`；不提供截图按钮、初始化、模型重载、服务启停或开机启动开关。截图 OCR 由原快捷键或托盘触发，新增复制用途由其独立快捷键触发；不要求新增托盘复制菜单。Xberg 配置、随包组件检查及修复、故障恢复及应用级设置仍统一置于「设置」页。后台或某项能力未就绪时明确说明原因，并按 XB-22 区分不依赖模型的图片复制。

#### Scenario: XB-24 简单设置不暴露编码细节
- **WHEN** 用户在截图设置区域配置图片复制上限及快捷键并保存
- **THEN** 按 O-14 / O-15 完成输入校验、热键冲突保护和持久化，后续截图使用新生效设置；页面不要求选择 PNG 压缩等级、调色板、缩放算法、输出格式或每次质量，不增加与本功能无关的配置、工具或页面。
