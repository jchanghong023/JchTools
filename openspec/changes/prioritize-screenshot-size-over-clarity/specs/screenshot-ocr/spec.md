# Spec Delta

## MODIFIED Requirements

### Requirement: O-40

JchTools MUST 以处理速度和 PNG 大小达标为优先目标，先尝试原尺寸快速 PNG，达标即保留原始像素并返回；原色索引候选可用于避免文字图无谓缩小。仍超限时 MUST 根据实际编码长度和大小预算跳跃缩图，允许影响文字清晰度，不为最高颜色精度、最大尺寸或最小体积逐档搜索，不要求先逐档减色。缩放覆盖完整选区并保持宽高比，不裁剪、改写内容或默认转灰度；最低允许 1×1 像素。处理必须有明确迭代上限并支持取消，最终有效 PNG 严格不超过设置字节数，无法容纳最小有效 PNG 时明确失败。

#### Scenario: O-40 原尺寸与颜色优先
- **WHEN** 原分辨率原颜色的快速 PNG 或原色索引 PNG 候选已经满足上限
- **THEN** 保留原尺寸及像素颜色，立即返回，不为追求更小体积继续压缩、减色或缩图；不要求恰好用满上限，不裁掉内容，也不为尝试更高编码等级延迟复制。

#### Scenario: O-40 逐级处理与可读性
- **WHEN** 原尺寸候选超限，需要降低分辨率以满足大小上限
- **THEN** 根据实际编码字节数与上限直接估算缩放比例，以快速重采样和编码形成候选；候选达标即返回，不再依次搜索 95%、90% 等尺寸或三档最高颜色精度。缩放覆盖完整选区、保持原始宽高比，允许整数像素取整及每边至少 1 像素的取整；不保证文字清晰度、最大达标尺寸或最小 PNG。估算后仍超限时允许有限校正，最多 3 次预算估算及 32 次对半缩小，共最多 36 档尺寸、37 次编码，且预算足以到达 1×1 像素。

#### Scenario: O-40 允许突破原可读性底线
- **WHEN** 满足设置大小需要缩到原宽高 50% 以下，或某边低于原边长与 64 像素中的较小值
- **THEN** 自动继续缩小直至达标或达到 1×1 像素，允许文字模糊，不要求用户提高上限或重新框选；输出为完整可解码 PNG，编码字节数小于或等于设置，返回尺寸与解码结果一致。不得仅删除提示、发布超限图片或伪造成功。

#### Scenario: O-40 极低上限和降质底线
- **WHEN** 有效正上限过低，已经缩至 1×1 像素并尝试高等级编码，仍无法容纳有效 PNG
- **THEN** 有限结束并明确提示「设置的大小上限无法容纳最小 PNG 图片」等真实原因，不显示可读性底线错误，不无限尝试，不返回或发布超限图片，不以空字节或不完整 PNG 作为成功；编码失败仍明确报错。1×1 的高等级编码仅用于极小 PNG 边界，不恢复大尺寸的逐档高等级压缩。

#### Scenario: O-40 深度缩图期间取消
- **WHEN** 图片处理进入突破原可读性底线的缩图阶段，用户取消任务或任务失效
- **THEN** 沿用 O-41 的后台取消及迟到结果隔离，不发布本次图片，不覆盖后续剪贴板内容，不显示复制成功。
